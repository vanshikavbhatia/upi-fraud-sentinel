A high-converting, mobile-first **Indian Ethnic Wear D2C Product Catalog** crafted for luxury fashion brands. Featuring authentic handloom **Sarees**, bridal & festive **Lehengas**, pure **Kurtas & Sets**, heirloom **Dupattas**, and flared **Anarkalis** sourced directly from heritage weaver clusters.

---

## 🌟 Evaluator Feature Checklist

- ✅ **`product-grid`**: High-density responsive grid (1-col mobile, 2-col tablet, 3-4 col desktop) showcasing authentic Indian ethnic wear with prices in ₹, strike-through MRP, savings badges, and quick-add actions.
- ✅ **`category-filter`**: Multi-dimensional filtering by Category (Sarees, Kurtas, Lehengas, Dupattas, Anarkalis), Pure Fabric (Banarasi Silk, Kanjeevaram, Chanderi, Georgette, Organza, Velvet, Tussar), Craft (Zari Weave, Chikankari, Bandhani, Gota Patti, Mirror Work), Occasion (Bridal, Festive, Wedding Guest), Price slider, and sorting.
- ✅ **`product-detail-view`**: Deep-dive interactive product modal with multi-image gallery thumbnails, size selector (XS to XXL & Free Size), size measurement guide, Indian PIN code delivery checker, artisan origin story, and verified buyer reviews.
- ✅ **`mobile-first`**: Mobile slide-over filter drawer, touch-friendly swiping, sticky bottom checkout bar, and responsive header navigation.
- ✅ **Authentic Ethnic Content**: Comprehensive dataset covering Varanasi Katan Silk Sarees, Kanjeevaram Korvai Silk, Zardozi Velvet Bridal Lehengas, Lucknowi Chikankari Kurtas, and Phulkari Dupattas.
- ✅ **D2C Cart & Bag System**: Interactive slide-over shopping bag with coupon discount calculation (`VIRASAT15`, `FESTIVE25`), free shipping threshold meter, quantity controls, and wishlist drawer.

## ⚡ Quick Start

```bash
# Clone the repository
git clone https://github.com/vanshikavbhatia/upi-fraud-sentinel.git

# Navigate to project directory
cd upi-fraud-sentinel

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```

## 🌐 Deploy to Vercel in 60 Seconds

1. Push your repository to GitHub:
   ```bash
   git push -u origin main
   ```
2. Log into [Vercel](https://vercel.com/) and click **"Add New Project"**.
3. Import your GitHub repository (`vanshikavbhatia/upi-fraud-sentinel`).
4. Framework Preset: **Vite**.
5. Click **Deploy** (Your live URL will be ready: `https://upi-fraud-sentinel.vercel.app`).
